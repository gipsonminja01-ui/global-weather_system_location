MFUMO WA HALI YA HEWA + LOCATION

1. Fungua index.html kwenye Chrome ukiwa na internet.
2. Bonyeza "Tumia GPS yangu".
3. Ruhusu Chrome kupata location.
4. Ramani itaweka alama ya GPS na kuonyesha joto, unyevu, upepo na utabiri wa siku tano.

Ikiwa GPS haitafanya kazi ukifungua faili moja kwa moja (file://):
- Fungua Command Prompt ndani ya folder.
- Endesha: python -m http.server 8000
- Fungua http://localhost:8000 kwenye Chrome.

Unahitaji internet kwa ramani na data ya hali ya hewa. Eneo la kuanzia ni Mikumi kwa makadirio; GPS halisi inaonekana tu baada ya ruhusa yako.
